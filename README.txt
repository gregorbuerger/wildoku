Wildoku 0.5.7

Testversion fuer den bestaetigten Update-Ablauf.

Wichtig:
- Die automatische Pruefung darf nur melden, dass eine neue Version verfuegbar ist.
- Erst "Jetzt aktualisieren" loest die Installation aus.
- "Spaeter" veraendert die laufende Version nicht.
- sw.js ist absichtlich byte-identisch zu 0.5.5, damit iOS nicht allein durch einen neuen Service Worker umschaltet.

Alle Dateien in denselben Wildoku-Ordner auf dem Webserver kopieren.
